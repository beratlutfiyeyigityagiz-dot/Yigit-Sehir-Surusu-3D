YIGIT SEHIR SURUSU 3D - GUNCEL SURUM

Render Web Service:
Build command: npm install
Start command: npm start
Runtime: Node

GitHub'a ZIP icerigini (public klasoru, server.js, package.json ve bu README) yukleyin.
Render'da bu depoyu Web Service olarak baglayin. Oyun, Render'in verdigi https adresinden acilmalidir.

Eklenenler:
- Hiz gostergesi (km/sa)
- Basili tutuldugunda nitro
- Drift ve ara gaz dugmeleri
- Gündüz / öğlen / gece aydinlatma modlari
- Çevrim ici oda icinde acilan oval yaris pisti ve 3-2-1 / BASLA geri sayimi
- Pist uzerindeki toplanabilir oyun kredileri
- Basit sinir disina cikma hasari ve tamir dugmesi
- Yarisi ilk bitiren oyuncuya 500 oyun kredisi (gercek para degil)

Notlar:
- Yarış ve oda sistemi için Render sunucusu gereklidir. HTML dosyasını telefonda doğrudan açmak çevrim içi bağlantıyı çalıştırmaz.
- Oyun kredileri tarayıcıda saklanır. Gerçek TL ödemesi, reklam izleme karşılığı para verme veya ödeme altyapısı ekli değildir.
- Bu sürümde 50 ayrı gerçek 3D araç modeli yoktur; mevcut gerçek Tesla ve Bugatti modelleri korunmuştur.
- Hasar sistemi şu aşamada harita sınırlarına çarpma için basit bir prototiptir; araç tamponlarının fiziksel olarak kopması/ezilmesi henüz eklenmemiştir.
- Kod sözdizimi kontrolleri yapılmıştır; canlı Render ve telefon tarayıcısı testi yapılmamıştır.

- Harita: uzatılmış ana yol, sağlı-sol yan yollar, bağlantı caddeleri ve genişletilmiş sürüş alanı.
